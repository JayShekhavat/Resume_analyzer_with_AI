1. Upload Resume (PDF)
2. Extract text using (NLP)
3. Identify skills
4. match resume with job description
5. give match score


## Component and their tools
UI -> Streamlit
NLP -> spaCy
Text Extraction -> pdfplumber
ML/NLP -> scikit-learn
Similarity -> TF-IDF + Cosine Similarity
